# Trading Term Catalog

这里存放的不是执行规则文件本身，而是“术语词典 + 模板索引”。

这层的目的有三个：

1. 给交易者先展示系统支持哪些市场语言。
2. 把术语和默认模板绑定起来，降低从词汇到配置的跳跃。
3. 把模板依赖的特征字段先沉淀成正式词典，而不是散在文档里。

当前先提供两类目录：

1. 术语目录：术语、默认模板、推荐动作、必需特征。
2. 特征目录：字段含义、值类型、作用域、相关术语。

当前代码里也已经有对应的检索入口：

1. `load_default_rule_template_selector()`：直接加载内置术语目录和特征目录。
2. `load_rule_template_selector_from_files(...)`：供上层传入自定义目录文件。
3. `RuleTemplateSelector.search_templates(...)`：按术语文本、阶段、动作、标签、可用字段筛选模板。

如果上层不想自己拼 selector 的返回结构，也可以直接用建议入口：

1. `load_default_rule_template_advisor()`：返回可直接给服务层或桥接层使用的 advisor。
2. `RuleTemplateAdvisor.suggest_from_text(...)`：输入术语文本，直接得到模板建议、缺失字段、字段中文标签和模板文件路径。
3. `RuleTemplateSuggestionResponse.to_dict()`：便于后续 JSON 化或桥接层透传。

当前先提供一份 A 股短线导向的第一批和第二批目录：

1. 入场术语：弱转强、炸板回封、卡位上位、补涨启动。
2. 观察放弃术语：龙头被替代放弃关注。
3. 持仓管理术语：分批止盈、反包失败退出、承接走弱退出。
4. 风控术语：情绪退潮冻结新开仓、高位炸板率恶化冻结新开仓、回封率下滑冻结新开仓、题材退潮冻结新开仓。

后续可以继续在这里补：

1. 卡位、补涨、反包失败、承接走弱。
2. 趋势和组合术语，例如多头排列、再平衡偏离修复。
3. 更细的 required_features 规范和字段解释。
